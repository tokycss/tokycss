# Installation

Getting started with Toky CSS requires only two files:

1. Your project styleguide
2. The Toky CSS stylesheet

## Quick Start

Add both stylesheets to the `<head>` of your document.

```html
<!-- Your project styleguide -->
<link rel="stylesheet" href="styleguide.css" />

<!-- Toky CSS -->
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/tokycss@0.1/dist/toky.min.css"
/>
```

Your styleguide loads first and defines your project's design decisions.

Toky CSS then uses those values throughout its token system, color system, typography system, spacing system, and theme system.

## That's It

Once loaded, Toky CSS immediately provides foundations for:

* Typography
* Colors
* Theming
* Forms
* Buttons
* Tables
* Navigation
* Layouts
* Spacing
* Focus states

You can begin building immediately without additional configuration.
