# Changelog

All notable changes to Toky CSS are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com),
and this project adheres to [Semantic Versioning](https://semver.org).

## [0.1.0] — 2026-06-18

### Added

- Initial public release
- Color system with OKLCH-based automatic tints, shades, and alpha variants
- Theme system with `light-dark()` and `data-theme` overrides
- Fluid typography scale (xs–9xl)
- 4px-based spacing system
- Border, outline, and radius tokens
- Effects system (blur, brightness, contrast, shadows, opacity, etc.)
- Animation and transition system with easing functions
- Layout grid engine with breakout support
- Semantic background and foreground tokens
- Status color tokens (success, warning, error, info)
- Focus ring tokens
- CSS reset and sensible HTML defaults
- Form styles, table styles, navigation, buttons, badges, dialogs
- Utility layer
- Gap and z-index tokens
- Split build output (variables-only and styles-only bundles)
